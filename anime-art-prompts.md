# 🎨 Anime Illustration Prompt Pack — Amazing Stories from the Bible

The story pages already have hidden picture slots. As soon as you save each image
with the **exact filename** below into the folder **`images\anime\`**, it appears on
the page automatically (with its caption). No slot = nothing shown, so the site looks
fine even half-finished.

> A ready-to-import CSV of every prompt below is in **`art-prompts.csv`** (repo root)
> for batch generation tools.

## How to use (about 10 minutes per story)

1. Open **Gemini** and pick the image model (Nano Banana).
2. Work on **one story at a time, in one chat** — after the first image, start the
   next prompt with *"Same characters and same art style as the previous image."*
   This keeps faces and costumes consistent.
3. Copy-paste one prompt per image. Ask for the aspect ratio shown if it comes out square.
4. Download and save into `images\anime\` with the exact filename shown
   (keep the name even if Gemini gives you a .jpg — just rename the whole thing,
   e.g. `joseph-1.png`; browsers don't mind).
5. Refresh the page — done!

**Style note baked into every prompt:** cute Japanese anime / Ghibli-style children's
storybook, soft watercolor, kid-friendly, no text in the image. If a result looks off,
just reply "cuter, softer, more storybook-like" and regenerate.

**Two standing rules for this site:**
- **No depiction of Jesus** in any New Testament image — we illustrate only the
  characters inside the parables (this is noted in every NT prompt).
- Nothing scary or graphic: babies always visibly safe, no one in danger up close,
  modest clothing throughout.
